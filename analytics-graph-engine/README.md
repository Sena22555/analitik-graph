# Analytics Graph Engine

Комбинированный граф для аналитики - объединяет граф зависимостей переменных и временной ряд событий с причинно-следственными связями.

## Возможности

- **Граф зависимостей переменных** - автоматически находит корреляции и зависимости между переменными
- **Временной ряд событий** - анализирует последовательность событий и причинно-следственные связи
- **Статистический анализ** - вычисляет корреляции (Pearson), плотность графа, временные паттерны
- **REST API** - полноценный HTTP API для создания и анализа графов
- **Математическая статистика** - использует Apache Commons Math для точных вычислений

## Быстрый старт

### 1. Сборка проекта

```bash
cd analytics-graph-engine
mvn clean package
```

### 2. Запуск

```bash
java -jar target/analytics-graph-engine-1.0.0.jar
```

Или с Maven:

```bash
mvn spring-boot:run
```

Сервер запустится на `http://localhost:8080`

### 3. Создание графа

```bash
curl -X POST http://localhost:8080/api/v1/graphs \
  -H "Content-Type: application/json" \
  -d '{
    "csvData": "temperature,humidity,pressure\n23.5,45,1013.25\n24.1,48,1013.50\n23.8,46,1013.10",
    "name": "Weather Data"
  }'
```

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/v1/graphs` | Создать новый граф из CSV |
| GET | `/api/v1/graphs` | Получить все графы |
| GET | `/api/v1/graphs/{id}` | Получить граф по ID |
| GET | `/api/v1/graphs/{id}/statistics` | Статистика графа |

| DELETE | `/api/v1/graphs/{id}` | Удалить граф |

## Основные компоненты

### AnalyticsGraph
Главный граф, который объединяет:
- Граф зависимостей переменных (dependency graph)
- Временной ряд событий (time series events)
- Матрицу смежности (adjacency matrix)
- Статистику и паттерны

### Variable
Узел в графе зависимостей:
- Название и тип переменной
- Массив значений
- Список зависимостей от других переменных
- Корреляции с другими переменными

### TimeSeriesEvent
Событие во временном ряду:
- Временная метка (timestamp)
- Значения всех переменных в момент события
- Предшественники и преемники (причинно-следственные связи)
- Уровень важности (severity)

### AnalyticsGraphEngine
Движок анализа, который:
- Вычисляет корреляции Пирсона между переменными
- Строит граф зависимостей (порог корреляции: 0.5)
- Анализирует причинно-следственные связи между событиями
- Находит временные паттерны в последовательности событий
- Вычисляет статистику графа (плотность, средняя корреляция)

## Алгоритмы

**Корреляции:** Pearson correlation coefficient
- Порог для зависимостей: 0.5
- Порог для сильных корреляций: 0.7

**Причинно-следственные связи:** Анализ изменений между последовательными событиями
- Порог изменения: 0.5

**Временные паттерны:** Поиск повторяющихся последовательностей из 3+ событий
- Минимальная частота: 2 повторения

**Плотность графа:** edge_count / (n * (n-1)), где n - количество переменных

## Примеры использования

### Анализ погодных данных

```bash
curl -X POST http://localhost:8080/api/v1/graphs \
  -H "Content-Type: application/json" \
  -d '{
    "csvData": "temperature,humidity,pressure\n23.5,45,1013.25\n24.1,48,1013.50\n23.8,46,1013.10\n24.5,49,1013.75\n23.2,44,1012.90",
    "name": "Weather Analytics"
  }'
```

Результат покажет:
- Сильную положительную корреляцию между температурой и влажностью (0.99)
- Зависимости между всеми тремя переменными
- Временную последовательность изменений погоды

### Производственная аналитика

```bash
curl -X POST http://localhost:8080/api/v1/graphs \
  -H "Content-Type: application/json" \
  -d '{
    "csvData": "production_rate,defect_rate,temperature\n95,2.1,62\n98,1.9,63\n92,3.2,61",
    "name": "Production Metrics"
  }'
```

Результат покажет:
- Отрицательную корреляцию между качеством и дефектами
- Влияние температуры на производительность
- Паттерны в изменении метрик
